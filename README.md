# VELOURA — Luxury Fragrance Landing Page

> **Elegance in Every Drop.**

VELOURA is a luxury fragrance landing page designed to create a premium and sophisticated digital brand experience. The project focuses on elegant typography, a dark luxury color palette, gold accents, responsive layouts, and subtle interactive effects.

The website presents VELOURA as a refined fragrance brand through a visually focused hero section, brand story, signature values, and carefully designed UI components.

## ✨ Features

* 🖤 Luxury dark-themed interface
* ✨ Gold/champagne visual accent system
* 🧴 Premium fragrance brand presentation
* 🎨 Custom hero section with background imagery
* 🧭 Navigation with hover animations
* 📖 Brand Story section
* 💎 Brand value cards
* 📱 Responsive design with CSS media queries
* 🔗 Social media icons using Font Awesome
* 🔤 Google Fonts integration
* 🎯 Interactive hover effects
* ♿ Semantic HTML structure and accessibility-focused attributes

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure
* **CSS3** — Layout, styling, animations, variables and responsive design
* **Google Fonts** — Typography
* **Font Awesome** — Social and interface icons

## 🎨 Design

VELOURA uses a carefully defined luxury color system built around:

* Deep black backgrounds
* Warm gold accents
* Champagne highlights
* Off-white typography
* Subtle borders and shadows

The CSS uses custom properties to maintain consistency across the visual system.

```css
--bg-primary: #080707;
--gold-primary: #C9A45C;
--gold-light: #E6C98A;
--text-primary: #F5F1E8;
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/veloura-luxury-fragrance-landing-page.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd veloura-luxury-fragrance-landing-page
```

### 3. Run the website

Open `index.html` directly in your browser or use the **Live Server** extension in VS Code.

## 📱 Responsive Design

The website includes responsive CSS breakpoints for different screen sizes.

The navigation changes at smaller screen widths, while typography, hero content, buttons, and other elements are adjusted to improve the viewing experience.
